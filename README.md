# google-quality-roadshow
This is a presentation for the roadshow of a new quality matrix for customer support agents. Images and other information are redacted to maintain confidentiality and privacy. The file introduces a navigable experience through linked slides by clicking textboxes.

The file wasn't exported into .pptx to maintain its original formatting in Google Slides which can be accessed here: <https://bit.ly/3RFqGGH>
